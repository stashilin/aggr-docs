# docs-site — портал документации «Депозиты v1»

Публичная витрина для **аналитиков и интеграторов**. Mintlify, русский язык.

Проектное решение и правила — [`../docs/portal-spec-2026-08-04.md`](../docs/portal-spec-2026-08-04.md).

## ⛔ Не запускать здесь `bmad-publish-mintlify`

Каталог когда-то был создан скиллом `bmad-publish-mintlify` из `_bmad-output/` и содержал
54 страницы BMAD-планирования. 2026-08-04 они удалены, каталог переделан в портал.

Скрипт `publish.py` **перегенерирует навигацию в `docs.json` при каждом запуске** — повторный
вызов скилла на этот каталог снесёт портал и вернёт BMAD-дамп.

Если BMAD-выгрузка когда-нибудь понадобится — только в другой каталог через `--out`.

## Правила письма

Аудитория — аналитики, не разработчики.

- **JSON запрещён.** Ни примеров тел, ни `curl`. Поля объясняются словами: как называется,
  что означает, что значит его отсутствие.
- **Механики нет.** HTTP-коды, заголовки, ретраи, форматы — только в API Reference.
- **Контрактные факты не копируются**, кроме двух ядровых тем (статусы/этапы и суммы) —
  они раскрыты намеренно, ради них портал и сделан.

## Копия спеки

Источник правды — `contract/openapi.yaml` в корне. Mintlify читает спеку только внутри своего
каталога, поэтому здесь лежит копия. Обновлять после изменения контракта:

```sh
cp contract/openapi.yaml docs-site/api-reference/openapi.yaml
```

Редактировать копию нельзя — правки вносятся в источник.
