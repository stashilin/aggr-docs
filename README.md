# aggr-docs — портал документации «Депозиты v1»

Публичная витрина для **аналитиков и интеграторов**. Mintlify, русский язык.

Это ЕДИНСТВЕННЫЙ дом доки: правки — только здесь. Контракт живёт в приватной репе aggr-contract; здесь лежит его копия для Mintlify.

## Что где

| Файл | Что это |
|---|---|
| `index.mdx` | как работает сервис, два варианта интеграции, путь платежа |
| `scenarios-payment.mdx` | путь заявки: оплата по шагам, h2h и redirect |
| `scenarios-exceptions.mdx` | путь заявки: возврат, истечение, отмена, ошибки создания |
| `sandbox.mdx` | песочница: документер, Run in Postman, мок-сервер, MCP |
| `status-stage.mdx` | **ядро.** Исход и этап: словари и правила чтения |
| `amounts.mdx` | **ядро.** Три суммы, недоплата и переплата |
| `reversal.mdx` | возврат и апелляция |
| `callbacks.mdx` | уведомления об изменениях |
| `failures.mdx` | ошибка запроса против неуспеха заявки, отмена |
| `api-reference/openapi.yaml` | **сгенерированная копия**, не редактировать |

## Правила письма

Аудитория — аналитики, не разработчики.

- **JSON запрещён.** Ни примеров тел, ни `curl`. Поля объясняются словами: как называется,
  что означает, что значит его отсутствие.
- **Механики нет.** HTTP-коды, заголовки, ретраи, форматы — только в API Reference.
- **Контрактные факты не копируются**, кроме двух ядровых тем (статусы/этапы и суммы) —
  они раскрыты намеренно, ради них портал и сделан.

## Копия спеки

Источник правды — `contract/openapi.yaml` в приватной репе aggr-contract. Mintlify читает спеку
только внутри репы доков, поэтому здесь лежит копия. Обновлять после изменения контракта:

```sh
cp ../aggr-contract/contract/openapi.yaml api-reference/openapi.yaml
```

Редактировать копию нельзя — правки вносятся в источник.
