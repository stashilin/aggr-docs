# aggr-docs — портал документации «Депозиты v1»

Публичная витрина для **аналитиков и интеграторов**. Mintlify, русский язык.

Это ЕДИНСТВЕННЫЙ дом доки: правки — только здесь. Контракт живёт в приватной репе aggr-contract; здесь лежит его копия для Mintlify.

## Что где

| `scenarios-payment.mdx` | путь заявки: оплата по шагам, h2h и redirect |

## Правила письма

Аудитория — аналитики, не разработчики.

- **JSON запрещён.** Ни примеров тел, ни `curl`. Поля объясняются словами: как называется,
  что означает, что значит его отсутствие.
- **Механики нет.** HTTP-коды, заголовки, ретраи, форматы — только в API Reference.
- **Контрактные факты не копируются**, кроме двух ядровых тем (статусы/этапы и суммы) —
  они раскрыты намеренно, ради них портал и сделан.

## Копия спеки

Источник правды — `contract/openapi.yaml` в приватной репе aggr-contract. Mintlify читает спеку
только внутри репы доков, поэтому здесь лежит копия. Она не украшение: без неё группа «Операции»
в навигации не собирается вовсе.

```sh
./scripts/sync-spec.sh          # обновить копию из контракта
./scripts/sync-spec.sh --check  # проверить, не разошлись ли (код 1 = разошлись)
```

Редактировать копию нельзя — правки вносятся в источник, потом sync.

**Проверку стоит гонять перед пушем.** Забытый sync ломает портал молча: страницы соберутся,
но покажут вчерашний контракт — а это хуже упавшей сборки, потому что никто не заметит.
Автосинк из CI контракта пока невозможен: deploy keys запрещены политикой организации,
для межрепного пуша нужен PAT, заведённый вручную.

Если репы лежат не рядом, путь к источнику задаётся явно:

```sh
AGGR_CONTRACT=/путь/к/contract/openapi.yaml ./scripts/sync-spec.sh --check
```
