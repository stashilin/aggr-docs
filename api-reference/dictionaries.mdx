## Главное правило

`method` и `bank` — независимые поля:

- `method` определяет механику перевода;
- `bank` определяет выбранный клиентом банк;
- название банка не зашивается в код метода;
- если банк не передан, его выбирает Сервис.

<Warning>
  Не составляйте значения вроде `sber_sbp` или `tbank_c2c`. Передавайте
  `method: sbp` и `bank: sber` как два отдельных параметра.
</Warning>

## Платёжные методы

| Код | Название | Описание |
| --- | --- | --- |
| `sbp` | СБП | Перевод по номеру телефона через Систему быстрых платежей |
| `c2c` | Перевод на карту | Перевод по номеру банковской карты |
| `nspk` | QR НСПК | Оплата по QR-коду или платёжной ссылке НСПК |
| `transgran` | Трансграничный перевод | Перевод на иностранные реквизиты по выданной инструкции |

Список может расширяться совместимо с v1. Неизвестный или недоступный метод вернёт
ошибку запроса; депозит при этом не создаётся.

Не каждый банк обязан поддерживать каждый метод. Если комбинация невозможна, Сервис
вернёт `400 BANK_NOT_SUPPORTED_FOR_METHOD`. Если код банка неизвестен —
`400 BANK_UNKNOWN`.

## Как передавать банк

Передавайте `bank`, когда клиент уже выбрал банк в вашем интерфейсе. Сервис постарается
выдать реквизиты в этом банке, чтобы перевод прошёл внутри банка. Если выбор банка клиенту
не показывается, поле можно не передавать — маршрут выберет Сервис.
