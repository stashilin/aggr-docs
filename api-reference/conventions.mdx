## Версионирование

Версия в пути (`/v1`). Без смены версии появляются новые необязательные поля, значения
словарей, банки и PSP — незнакомые поля и значения игнорируйте. Ломающие изменения — только
как `/v2`. Устаревание анонсируется заголовками `Deprecation` и `Sunset`.

## Лимиты

Лимиты запросов и сумм согласуются при подключении.

- Превышение частоты — `429 RATE_LIMIT_EXCEEDED` с заголовком `Retry-After`: повторяйте не
  раньше указанного срока.
- Сумма вне диапазона — `422 AMOUNT_OUT_OF_RANGE`; границы в ответе не сообщаются.

## Форматы

- HTTPS, TLS ≥ 1.2; тела — JSON в UTF-8, `content-type: application/json`.
- Имена полей — `snake_case`; словарные значения — UPPERCASE (`PENDING`, `SUCCESS`, …).
- Даты — ISO 8601 в UTC: `2026-07-17T14:35:45Z`.
- Суммы — number, не более 2 знаков после запятой. Валюта — ISO 4217, сейчас только `RUB`.
- Поля со значением `null` в тела не включаются.

## Трассировка

Передавайте `x-request-id` (иначе Сервис сгенерирует его сам; в обоих случаях он возвращается
в ответе) и логируйте его.

## Что сообщать в поддержку

`transaction_id`, `occurred_at` колбэка и `x-request-id` — расшифровка каждого в
[Регламенте](/reglament#трассировка-и-поддержка).
